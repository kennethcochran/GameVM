## ADDED Requirements

### Requirement: Offset-based references
All AST nodes generated by the `Pascal` and `CSharp` frontends MUST reference child nodes and sibling nodes using 32-bit offsets within the slab rather than object references.

#### Scenario: Building a binary expression
- **WHEN** a parser processes an addition operation (`A + B`)
- **THEN** it stores the offset of `A` and `B` inside the `BinaryOp` node block in the AST slab.

### Requirement: Enum-based Node Typing
AST Nodes MUST use an enum discriminator (`AstNodeKind`) encoded in the metadata header to denote their type rather than relying on class polymorphism and `is`/`as` operators.

#### Scenario: Dispatching based on node type
- **WHEN** an evaluator or code generator processes a node
- **THEN** it decodes the metadata header to get `node.Kind` (the enum value) and switches on it instead of relying on virtual `Accept(Visitor)` dispatch.
